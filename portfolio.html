LIVE RESPONSIVE WEB RADIO

PROMETEI FM / RADIO LAB

An independently built public radio website, not just a concept: visitors can tune into a shared owner-PC live MP3 stream. The product combines Cloudflare Pages Functions, Workers KV station control, real track metadata and a 36-hour radio log, an official YouTube playlist as a timed backup, accessible controls, and seven-language mobile-friendly pages. The 20-minute failover uses verified PC signal status; full live outage testing is ongoing. Public broadcasting depends on music rights and a running operator PC.
