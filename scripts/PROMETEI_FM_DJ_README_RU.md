# PROMETEI FM — Owner's Windows DJ

Медиатека: `C:\TRADER_BOT\MUSIC FOR PROMETEI FM\Моя_YouTube_Медиатека`.
Проверено через NEXUS: 760 MP3 + 1 WebM. `ffmpeg.exe`, `ffprobe.exe`, `python.exe` найдены.

## Как запустить
В одной папке должны быть `START_PROMETEI_FM.cmd` и `prometei_fm_dj.py`.
Запуск через двойной клик `START_PROMETEI_FM.cmd`, затем выбери:

- **1 — SCAN:** просканировать каталог и создать `PROMETEI_FM_RUNTIME/MUSIC_CATALOG.json` и `NAMES_TO_REVIEW.csv`. Без вещания, без загрузки звука в облако.
- **2 — YouTube Live:** передавать музыку с ПК на прямую трансляцию YouTube и использовать официальный плеер PROMETEI FM.
- **3 — Icecast:** передавать музыку на радиосервер, доступный публично по HTTPS. Все слушатели слышат один аудиопоток.

### Корректные названия
Порядок: `TITLE_CORRECTIONS.csv` (ручное исправление по относительному имени файла) → MP3/FLAC tags → `.info.json` из yt-dlp → имя файла.
Если исполнитель не указан, программа его не выдумывает. В `NAMES_TO_REVIEW.csv` перечислены записи для проверки.
Чтобы исправить, добавь строку в `TITLE_CORRECTIONS.csv` с колонками `file,artist,title` и перезапусти сканирование.
Каждый запуск вещания заново случайно перемешивает весь список. Один файл играет не более одного раза за цикл из 761 песни.

### История 36 часов
Все прозвучавшие записи попадают в `PROMETEI_FM_RUNTIME/PLAY_HISTORY_LAST_36H.json` с временем начала и метаданными.
Для ПУБЛИЧНОЙ общей истории сайт использует `GET /api/fm/history`, а DJ отправляет подписанные события `POST /api/fm/history` и heartbeat.
Нужны KV binding `FM_STATE` и secret `FM_DJ_TOKEN` в Cloudflare Pages. При запуске программа попросит токен и не сохранит его на диск.
Если Cloudflare не настроен или нет токена — история остаётся только на ПК. Сайт никогда не показывает локальную историю посетителя как общий журнал вещания.
Cloudflare KV имеет задержку согласованности, обычно изменения видны не мгновенно; при отсутствии эфира состояние LIVE затухает.

### YouTube Live
Создай разрешённый прямой эфир на своём YouTube-канале (с включёнными прямыми эфирами), найди публичный 11-символьный video ID и потоковый ключ YouTube Studio.
DJ спросит ID и ключ отдельно. Ключ не отправляется на PROMETEI FM и не сохраняется в GitHub.
FFmpeg создаёт анимированную звуковую волну из твоей музыки; отдельный OBS для этого режима не нужен.
Если Cloudflare KV/DJ token настроены, DJ переключит сайт на выбранный live video ID. В противном случае надо вручную переключить источник в DJ Studio после настройки Cloudflare.

### Icecast
Нужен запущенный Icecast-совместимый сервер: адрес, source-порт, пароль источника и публичный HTTPS URL для слушателей.
DJ предложит ввести всё при старте. Не используй localhost в адресе для слушателей; сайт работает через HTTPS.
FFmpeg отправляет непрерывный MP3 поток из разнородных MP3/WebM без разрыва соединения между треками.

### Авторские права и безопасность
Запускай публичное вещание только при наличии прав на передачу каждого трека. Покупка/скачивание музыки и YouTube Premium не являются разрешением на интернет-радиовещание.
Перед стартом требуется отдельно ввести `YES` в окне вещания. Никакие треки сами не публикуются, пока оператор не запустил эфир.
Говорящие об артисте и названии теги иногда ошибочны: редактируй `TITLE_CORRECTIONS.csv` перед эфиром.
Выплаты и заказы платных песен не подключаются. Имена файлов/приватные директории не отправляются на сайт; только метаданные реально начатых передач.
