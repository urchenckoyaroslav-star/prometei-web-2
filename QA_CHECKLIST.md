# Site acceptance checklist

- [ ] Desktop 1440 × 900 and 1920 × 1080: no clipping, hero interaction readable.
- [ ] Tablet 768 × 1024: header, sections and cards reflow properly.
- [ ] Mobile 390 × 844 and 320 × 568: no horizontal overflow; hamburger links functional; full text readable.
- [ ] Language menu changes each primary home-page label in all seven languages and survives reload.
- [ ] Bluetooth/LAN/Internet/Mixed mode switch works with touch, pointer and keyboard.
- [ ] Motion reduced when OS `prefers-reduced-motion` is active.
- [ ] Public Play link opens PROMETEI (`com.meshnetwork.app`); PHANTOM is explicitly closed test, PokoNap explicitly not published.
- [ ] `app-ads.txt` exact publisher ID confirmed in AdMob and App Store website hostname matches.
- [ ] Policies reviewed against real Android builds, SDKs, data safety, privacy and applicable laws.
- [ ] External deletion request mechanism actually works; do not ask users to disclose personal data in public GitHub Issues.
- [ ] Real production domain and SEO sitemap after hosting is live.
